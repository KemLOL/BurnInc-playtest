    DISTRICT 04 · OPERATOR COPY Disposal rules

    Processing a load

    1. Receive the load.
    2. Check for blue-sealed sheets.
    3. Check the disposal request against the load. Return unlisted items, except blue-sealed sheets.
    4. Process the remaining items as listed.
    5. Certify and return the receipt.

    Blue-sealed sheets

    Set them aside. Sleeve and file them for district collection.

    Passports

    • Require a valid passport. Match its name and ID to the request, check it has not expired, and confirm today’s request date.
    • Show these rules if the passport is missing.
    • For missing or invalid papers, stamp Reject on the request and return the paperwork and intact load.
